[1] OVERVIEW & PURPOSE
--------------------------------------------------------------------------------
This repository hosts driver binaries, translation layers, and packaging scripts
tailored for Project Sakura GameDeck and Android container gaming environments
(such as Winlator / Winlator CMod / Glibc containers).

Components are packaged into Winlator Container Packages (.wcp files), which are
zstandard-compressed tar archives (tar.zst) that the Android container's content
manager / package installer extracts into the appropriate Wine prefix locations.

[3] BUILD UTILITY (package_wcp.py)
--------------------------------------------------------------------------------
- Script: package_wcp.py (Python 3 executable)
- Requirements: GNU tar with --zstd support, zstd CLI
- Responsibilities:
  1. Locates turnip-latest, dxvk-sarek-latest, and vkd3d-latest in repo root.
  2. Compresses component directories directly with tar --zstd if profile.json / meta.json exists.
  3. Provides fallback staging if profile.json is absent.
  4. Places built .wcp packages in releases/.
  5. Computes and generates SHA256 checksums in releases/SHA256SUMS.txt.
  6. Cleans up any scratch temporary directories after execution.

- How to build packages:
  Run command: `python3 package_wcp.py`

  up to LIBC_R (API 30) and API 26-29 AHardwareBuffer/sync functions, enabling full
  out-of-the-box compatibility on Android 12 (SDK 31), Android 13 (SDK 33), and
  Android 14+ (SDK 34+) without triggering Winlator API version blocks.
- Fix 4: Added .gitignore covering releases/, build_wcp_temp/, *.wcp, and Python
  cache directories.


[5] WINLATOR .WCP SPECIFICATION SUMMARY
--------------------------------------------------------------------------------
- A .wcp file is a tar archive compressed with zstd: `tar --zstd -cf package.wcp -C <dir> .`
- Driver packages use `meta.json` at root:
  {
    "schemaVersion": 1,
    "name": "...",
    "description": "...",
    "author": "...",
    "packageVersion": "...",
    "vendor": "...",
    "driverVersion": "...",
    "minApi": 31,
    "libraryName": "vulkan.turnip.so"
  }
- Component packages (DXVK, VKD3D, Wine, Box64, FEX) use `profile.json` at root:
  {
    "type": "DXVK" | "VKD3D" | "WINE" | ...,
    "versionName": "...",
    "versionCode": 1,
    "description": "...",
    "files": [
      { "source": "relative/path/in/archive.dll", "target": "${system32}/file.dll" },
      { "source": "relative/path/in/archive.dll", "target": "${syswow64}/file.dll" }
    ]
  }
