[1] OVERVIEW & PURPOSE
--------------------------------------------------------------------------------
This repository hosts driver binaries, translation layers, and packaging scripts
tailored for Project Sakura GameDeck and Android container gaming environments
(such as Winlator / Winlator CMod / Glibc containers).

Components are packaged into:
1. Custom Driver ZIP archives (.zip) for GPU drivers (Turnip), containing meta.json
   and vulkan.turnip.so at the archive root for standard Android / Winlator driver loaders.
2. Winlator Container Packages (.wcp files), which are zstandard-compressed tar archives
   (tar.zst) that the Android container extracts into Wine prefix locations based on profile.json.


[2] COMPONENT DIRECTORIES & ASSETS
--------------------------------------------------------------------------------
1. turnip-latest/
   - Component: Freedreno Turnip Vulkan Driver
   - Version: 26.2.0 (Compiled with Android NDK 30, Vulkan 1.3/4, minApi 31)
   - Manifest: meta.json (Schema Version 1)
   - Library: vulkan.turnip.so
   - Compatibility: Android 12+ (SDK 31+ / Android 12, 13, 14, 15)
   - Output: releases/turnip-latest.zip

2. dxvk-sarek-latest/
   - Component: DXVK Sarek (DirectX 8, 9, 10, 11 & DirectDraw translation to Vulkan)
   - Version: 1.12.0-sarek
   - Structure:
     * x64/ (64-bit DLLs: dxgi.dll, d3d11.dll, d3d10core.dll, d3d9.dll, d3d8.dll, ddraw.dll)
     * x32/ (32-bit DLLs: dxgi.dll, d3d11.dll, d3d10core.dll, d3d9.dll, d3d8.dll, ddraw.dll)
     * profile.json (Maps x64 DLLs -> ${system32} and x32 DLLs -> ${syswow64})
   - Output: releases/dxvk-sarek-latest.wcp


[3] BUILD UTILITY (package_wcp.py)
--------------------------------------------------------------------------------
- Script: package_wcp.py (Python 3 executable)
- Requirements: GNU tar with --zstd support (for .wcp), Python zipfile (for .zip)
- Responsibilities:
  1. Locates turnip-latest and dxvk-sarek-latest in repo root.
  2. Packages turnip-latest into a standard custom driver .zip archive (turnip-latest.zip).
  3. Compresses dxvk-sarek-latest into a Winlator container package (dxvk-sarek-latest.wcp).
  4. Places built packages in releases/.
  5. Computes and generates SHA256 checksums for all packages in releases/SHA256SUMS.txt.
  6. Cleans up any scratch temporary directories after execution.

- How to build packages:
  Run command: `python3 package_wcp.py`

[5] PACKAGE SPECIFICATION SUMMARY
--------------------------------------------------------------------------------
- Custom Driver (.zip): Standard zip archive with `meta.json` and `vulkan.turnip.so` at root:
  {
    "schemaVersion": 1,
    "name": "...",
    "description": "...",
    "author": "...",
    "packageVersion": "...",
    "vendor": "...",
    "driverVersion": "...",
    "minApi": 31,
    "libraryName": "vulkan.turnip.so"
  }
- Container Package (.wcp): A tar archive compressed with zstd (`tar --zstd -cf package.wcp -C <dir> .`)
  with `profile.json` at root:
  {
    "type": "DXVK" | "WINE" | ...,
    "versionName": "...",
    "versionCode": 1,
    "description": "...",
    "files": [
      { "source": "relative/path/in/archive.dll", "target": "${system32}/file.dll" },
      { "source": "relative/path/in/archive.dll", "target": "${syswow64}/file.dll" }
    ]
  }
